依旧是品控非常稳定的 cosatu 组合（COP/hisa镜/唯Tu）的一首歌，小洛的生日会也唱过这首，调整了编曲与一些词，但是上面几段还是不变的喵。

昨天星河君又用 WorkBuddy 做了一个基于开源项目 ActivityWatch 的 AI 智能归类+HTML 看板，主要是给自己用的，近期不会开源。这个工具就是给 ActivityWatch 加了个 AI 自动分类层，因为 ActivityWatch 原来就是手工分类，太烦了喵，星河君真的不堪重负，懒得去 Category Builder 加新规则了喵。Python 读取 AW 采集的窗口活动（应用名+标题），清洗去重后调用 DeepSeek API，按 17 个细分类别（编程开发、视频娱乐、AI 对话等）自动标注。分类结果写回 AW，再用 Chart.js 生成自包含 HTML 看板——数据内嵌、双击即开、不用服务器。星河君又让 WorkBuddy 写了一个一键启动的 bat 脚本，随时随地双击脚本，就能在弹出的网页中查看自己电脑的使用情况（今天/3天/7天），还有一键生成长图的功能，图 2 为 demo 网页生成的长图。注意这是模拟活动生成的数据，如果用真实数据，那么大家不都看到星河君最近在干什么了喵，这可不好喵。图 3 是这个工具大概的架构。

说实话，AI Agent 是真好用，我想到什么，它就能帮我做什么，全程星河君写了 0 条代码，只负责架构+测试+验证工作，AI Agent 就能帮我落地下来。

另外不要再说我强了，vibe coding 的功劳，大多还是得归 Agent 啊！
