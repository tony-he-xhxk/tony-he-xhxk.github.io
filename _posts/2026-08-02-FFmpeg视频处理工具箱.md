星河君一直没有找到能够方便处理视频的图形界面软件，于是今天利用 WorkBuddy，vibe 了一个基于 FFmpeg 的视频处理工具箱。说实话，Vibe Coding 是真方便啊。

先声明一下，这又是一个星河君自己做的 side project，不涉及任何商业用途，仅为技术工具分享。然后声明二下，这个工具调用本地算力运行，你的隐私不会被上传到任何云端服务器。（星河君也没有啊，服务器算力多贵啊。）因为在本地运行，运行速度与性能与硬件相关，与工具本身无关哦；如果有运行中短时发热与风扇功率飙升的情况，属于正常现象，在结束任务之后这一现象会完全消失。

这个工具用的是我最熟悉的 Python 语言，最基础的 tkinter 图形化界面，最好用的 FFmpeg 作为工具进行了开发。（说实话就是给 FFmpeg 的三个重要功能进行了一个图形化而已。）

这个工具必须在 Windows 10/11 系统上运行。实际上星河君是懒得做跨平台，也懒得封装成 exe，足见星河君有多么懒。🤣

但是使用起来是非常方便的喵，首先你需要准备：

- 通过 FFmpeg 官网（ffmpeg.org）下载的 FFmpeg 的 Windows 版本
- Python 3.10 及以上版本（需要包含 tkinter）并添加到系统环境变量
- 通过 pip 安装 pillow 包（在 cmd 中运行 `pip install pillow`）

然后，把我的仓库 clone 到本地，双击 bat 脚本运行，键入选项回车，就可以启动对应的 Python 脚本了喵！工具会自动检测并浏览到系统中 FFmpeg 的路径，如果找不到请通过文件选择器浏览到 FFmpeg.exe。然后通过文件浏览器浏览到你需要处理的视频文件，在傻瓜式的输入框中填入参数（视频大小裁剪工具是在弹出的视频画面预览界面通过鼠标拖动裁剪框），点击下面的处理按钮（如"开始裁剪"）就可以了喵，输出的视频文件会保持原有格式，自动导出到同一目录下。

每个工具的下方都有滚动式的终端输出展示，可以复制喵，方便定位问题与处理喵。

这个工具也已经在第一时间开源到了 GitHub 上，仓库地址为：

[https://github.com/tony-he-xhxk/FFmpegToolsGui](https://github.com/tony-he-xhxk/FFmpegToolsGui)
